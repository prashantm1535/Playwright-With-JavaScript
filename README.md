## 📌 Project Overview

This repository contains a structured Playwright automation framework built using JavaScript and Node.js.

It demonstrates end-to-end UI testing, API validation, framework design principles, and CI/CD integration following industry best practices.

The goal of this project is to build a stable, scalable, and maintainable automation framework aligned with SDET standards.

---

## 🧰 Tech Stack

* Playwright Test Runner
* JavaScript (ES6+)
* Node.js
* HTML Reporter
* GitHub Actions (CI/CD)

---

## 🌐 Cross-Browser Support

This framework supports execution on:

* Chromium
* Firefox
* WebKit

Parallel execution is enabled via Playwright configuration.

## ⚙️ Installation

Clone the repository:

```
git clone <repo-url>
cd <repo-name>
```

Install dependencies:

```
npm install
```

Install browsers:

```
npx playwright install
```

---

## ▶️ Running Tests

Run all tests:

```
npx playwright test
```

Run in headed mode:

```
npx playwright test --headed
```

Run in a specific browser:

```
npx playwright test --project=chromium
```

---

## 📊 Reporting

After execution, open the HTML report:

```
npx playwright show-report
```
